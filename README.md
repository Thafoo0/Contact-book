# [Contact Book]

A simple full-stack web application built to practice backend handling with Javalin and frontend communication using Fetch API.

## Description

This project demonstrates how to handle HTTP requests (GET and POST) between a Java backend and a  little bit of JavaScript frontend. The server processes incoming JSON data, applies business logic, and returns the modified data to the client. It's a practical hands-on exercise to bridge the gap between theory and real-world web development.

## Tech Stack

- Backend: Java, Javalin Framework
- Frontend: HTML5, CSS, JavaScript
- Data Format: JSON
- Server: Javalin built-in (Port 7070)

## How to Run / Setup

1. Clone the repository:
   git clone [https://github.com/Thafoo0/Contact-book.git]

2. Navigate to the project folder.

3. Run the main Java class to start the Javalin server.

4. Open your browser and go to http://localhost:7070

5. Interact with the frontend to send/receive data via Fetch.
